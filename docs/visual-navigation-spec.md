# 隐式视觉导航与可选参考轨迹规格增量

版本：1.0（2026-09-29）。依据本轮侧聊交接及用户“根据讨论更新文档”指令整理。方向已收敛；具体网络、训练量与阈值由实施实验确定。本文补充 [PRD](PRD.md) 与[多模态学习规格](multimodal-learning-spec.md)，2 项新增、9 项修订的任务拆分已获批准并发布；不表示无参考路线观测、驾驶模型或迁移能力已经实现。

## Problem Statement

现有主线将真实图像、本车状态和预录航点一起输入策略，但强制要求历史路线，无法直接用于没有录过的道路。只在歌利亚训练也可能学到“见到这个地标就转向”，而非结合导航、速度和车辆状态选择动作。用户希望先完成歌利亚并通过 RL 持续改进，随后能在游戏中设定目的地，让策略选择正确道路、合理行驶，不必严格压着屏幕中的线。

## Solution

主线改为：真实 RGB 历史中的道路与导航指引、本车状态、因果动作历史，加上可选的独立历史参考航点，经过 BC 初始化后用 SAC 自主学习。允许网络隐式学习循迹线特征，不把专用线条提取器、像素分割或米制几何设为全局前置。训练和评估必须覆盖无历史航点条件，不能只在部署时突然删掉输入。

首版正式验收仍只针对原车原调校、固定条件的官方歌利亚；其成绩可以使用提前声明的参考辅助配置。小规模导航与迁移实验单独报告，不阻塞首次 BC/SAC 或歌利亚正式验收，也不能凭歌利亚完赛宣称任意道路驾驶。自由漫游的长期无人值守与自动到达不加入本次首版承诺。

## User Stories

1. 作为项目使用者，我希望策略实际利用画面中的道路和导航指引，以便在没有预录航点时也有正确去向的信息。
2. 作为驾驶策略实验者，我希望历史航点是可选先验，以便利用已有数据，同时保留跨路线的能力路径。
3. 作为使用者，我希望导航决定走哪条道路而非要求轮胎严格压线，以便策略选择合理赛车线、刹车点和局部避让。
4. 作为数据采集者，我希望记录导航设置、可见性依据和目的地变更，以便解释路口动作差异。
5. 作为训练者，我希望同一路口有不同导航去向的示范，以便削弱地标与单一动作之间的错误关联。
6. 作为训练者，我希望同一导航覆盖不同速度、横向位置和朝向偏差，以便策略结合车辆状态控制。
7. 作为训练者，我希望少量可信短段即可启动最小 BC，以便尽早查看闭环失败并针对性补数据。
8. 作为训练者，我希望失败经验与正确示范分开，以免把全部人工失误当作应复制的动作。
9. 作为训练者，我希望先前动作以真实时间和缺失掩码进入历史，以便学习控制响应且不泄漏当前监督目标。
10. 作为实验者，我希望区分主动不用参考、参考缺失和参考损坏，以便诊断降级而不混淆模型条件。
11. 作为评估者，我希望按独立回合及路段划分训练、开发与最终留出，以便区分记忆、同路复测和陌生路段迁移。
12. 作为评估者，我希望对有参考与无参考配置分别报告全部尝试，以便公平理解性能及失败。
13. 作为使用者，我希望导航遮挡、无导航岔路和偏航时有明确行为边界，以免策略在意图未知时假装知道目的地。
14. 作为训练者，我希望 RL 在实际无参考条件下持续采样和改进，以免能力永久依赖 BC 示范或预录航点。
15. 作为评估者，我希望奖励与到达判定具有独立依据，以免“贴线”或靠近目的地被误计为有效完成。
16. 作为实验者，我希望更换模型后可重建视觉和动作历史，以便续训时不会混用不同含义的数据。
17. 作为使用者，我希望已有因果观测与回放成果继续可用，以便新方向不要求重做已有验收。
18. 作为使用者，我希望看到导航条件改变后的真实选路及未训练路段结果，以便判断迁移进展，而非只看注意力图或 loss。
19. 作为后续自由驾驶使用者，我希望由游戏规划全局导航、策略负责驾驶、任务管理判断到达，以便各自职责可验证。
20. 作为使用者，我希望导航训练与驾驶进步仍遵守无接管、无倒带及反奖励投机规则，以便高分代表真实能力。

## Implementation Decisions

### 输入、职责与兼容

- 观测构造器保留图像、本车运动状态、参考先验和因果历史的来源、版本、时间与掩码。观测可构造、策略支持该输入条件、任务证据足以驾驶/评分是三个独立判断。
- 参考配置显式区分“必须提供”“可选”“禁用”。旧版契约继续按必须提供解释；新视觉导航配置允许可选或禁用。缺省不得悄悄改变旧运行的含义。
- 可选模式下，有效图像/本车状态不会仅因没有参考文件而失效；缺省、定位歧义、越界或坏资产分别报告，航点遮蔽。坏资产先按完整性规则报告/隔离，不能重命名成正常缺省。只有已训练且验收相应无参考条件的策略才能继续；必选模式仍拒绝不可用参考，禁用模式不读取或缓存参考输入。
- 独立任务评测可以使用核实过的路线、走廊、出口和检查点依据，即使 actor 不接收它们。评测数据不得经观测、缓存或模型选择泄漏回 actor；没有足够任务证据时允许离线训练，不能捏造合法进度或自动晋升。
- 屏幕循迹线属于允许的导航条件；遥测单值 `NormalizedDrivingLine` 不作为未来导航路径的替代。本地该字段语义与可用性未核实，本规格不要求解析它。
- 最小候选沿用图像历史编码、本车状态融合及双轴 BC→SAC；参考分支带显式掩码，动作历史使用当次决策之前已知的动作与时间。当前预测目标和之后下发的动作不得出现在该次 actor 输入；冷启动、暂停和恢复后的历史缺口不补成已知中性动作。
- 第一候选不把绝对世界坐标、全局赛程里程、目的地标识或回合标识当作记忆路口动作的输入；这些可以留作采集与独立评测元数据。局部航点保持本车坐标。若后续研究额外意图输入，单独版本化并重新评估。
- 已解析的速度、车体速度及角速度、航向与候选加速度/滑移字段明确区分；新增运动量需先实测语义。相机仍为追尾远档位，动态距离不当作固定外参；缩放/裁剪须用远处线条和岔路样例检查信息保留，具体分辨率与网络规模未冻结。
- 暂时遮挡可使用已验证的短期视觉/动作历史；持续无明确导航的岔路，需要其他已验证意图来源或停止/显式回退。导航状态的人工标记可用于诊断，不能假称已部署可靠在线识别器。既有推理超时、失焦和断流释放要求保留。

### 数据与学习

- 初始同步示范包含导航条件、可信动作、不同入弯状态及无历史航点的训练视图；参考屏蔽的比例/课程、原因与随机性固定并记录。人为屏蔽已有参考不等于已验证陌生道路。
- 首批少量可信短段先跑通采集→训练→预测；再按闭环失败补数据。交接中的分钟数、圈数和段数是建议起点，不是配额或足够性的保证。失误、接管和恢复经验保留，未经甄别不进入正确动作 BC 标签。
- 导航专项数据在同一路口切换目的地，覆盖可实现的左/右/直行去向；同一导航覆盖不同速度、位置和朝向。无法在本机显示某种指引时记录限制，不用虚构帧代替实机证据。
- 按独立回合划分数据，跨路线结论另按未训练路段留出；所有已用于调参、选模型或失败诊断的数据只算开发数据。参考来自独立历史，未来轨迹只用于合法前向片段中的监督目标。
- BC、SAC 采样、冻结评估及续训均记录参考模式、导航条件和历史版本。无参考能力要有真实交互和冻结评估证据；BC loss 下降或部署时突然移除航点不能替代。SAC 可以超越示范，不设永久小残差约束。

### 奖励、自由驾驶与证据

- 导航负责选路，驾驶奖励面向独立核实的正确路线推进、到达、时间与稳定/接触；不把持续贴近循迹线作为最终目标。仅靠欧氏距离减少、导航重算后的剩余距离跳变或参考定位跳跃不得获得虚假进步。
- 自由驾驶候选流程为用户设目的地、游戏显示选路、策略控制、任务管理独立判断去向和到达。先被动核验本机线条显示、岔路、遮挡、偏航重算和到达提示；无法验证时列出失败分支，不承诺无目的地坐标也能在所有场景导航。
- 到达不能等同于导航线消失或速度归零；后续任务协议须预先指定目的地/结束区、独立画面或状态证据、停车条件、超时和失败结果。改目的地或重算路线须有任务阶段边界，未能可靠识别时不训练对应进度奖励。
- 三种证据分开：视觉进入计算、策略正确响应导航条件、真实驾驶收益。使用可见导航不是作弊；错误地只按地标/HUD 关联动作、忽略车辆状态才是待检验问题。黑图退化、移线敏感、注意力热图和单次成功都不是充分证明。

## Testing Decisions

沿用用户已经确认的最高测试边界：输入固定配置和真实/回放环境，经实验运行入口检查观测、实际动作、完整尝试及版本晋升。复用既有因果观测、故障回放和冻结驾驶评估方式，不新增要求用户再选择的测试入口。

| 场景 | 可验收的外部结果 |
|---|---|
| 相同录制分别提供/省略参考 | 新可选配置能回放两类观测；无参考有明确掩码与原因，旧必选配置仍拒绝缺失 |
| 损坏参考、错路或定位歧义 | 不伪造航点，不静默当成正常缺省；独立任务有效性不因 actor 可构造而通过 |
| 无参考运行后更改评测路线或未来数据 | 过去的 actor 输入不变；禁用参考分支没有隐藏读入，任务报告可独立变化 |
| 动作历史冷启动、迟到及跨恢复 | 缺失掩码可见；当次标签和未来命令不回流输入；断点后不沿用旧片段历史 |
| 独立回合 BC 与模型保存/加载 | 两种参考条件的留出预测、失败和来源可追溯；同输入加载前后行为一致 |
| 同一路口改变导航 | 冻结条件、预先标明出口，在有界实跑中统计选对出口、失败和接管；离线响应只是辅助诊断 |
| 同导航改变进入状态 | 对不同速度/位置/朝向报告通过、恢复和平顺；不是只要求画面一变动作就变 |
| 未训练路段、有导航、无历史航点 | 按路段留出及冻结协议报告所有尝试；正/负结果均可完成研究，但不能把失败称为迁移成功 |
| 贴线、切地形、偏航重算、消失的线 | 已知奖励反例不优于有效完成；不凭距离跳变、线消失或停车判成功 |
| 有参考/无参考模式切换和续训 | 数据、模型与评测条件兼容性可检查；评测批次冻结，不静默切换后混算成绩 |

软件测试使用独立预期而非复制实现；真实输入、驾驶、学习改善及导航迁移分别需要对应证据。专项导航/迁移实验不阻塞歌利亚主线；尚未完成时不得声称相关能力已通过。

## Out of Scope

本次不启动游戏、录制、训练或驾驶，不改动 #26 已交付代码或放宽其现有验收；不新增对手、多车辆或任意道路的首版正式承诺。不要求完整导航 API、目的地世界坐标、专用循迹线提取器、完整道路分割、任意位置复位、模拟加速、多实例、外部权重移植或特定神经网络。自由漫游长期自主采样与奖励实现，在导航及到达依据被核实后另行切片。
