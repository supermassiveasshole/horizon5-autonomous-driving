# 奖励、恢复与有效成绩

状态：对应 [PRD v1.0](PRD.md) 的奖励与有效性专项设计，尚未实现或实机验证。范围已明确允许正常合理切弯、记录偶发接触，不认可依赖持续蹭墙、倒带或复位的成绩提升；可靠默认版本与激进候选均遵守这些规则。

## 目标与评分职责

目标是遵守约定规则完成任务，并改善用时、可靠性和平顺程度。训练奖励帮助策略学习；正式成绩通过独立有效性检查后才用于比较，不能把违规与圈速加权成一个允许相互抵消的总分。独立检查是不同的判断逻辑，并不意味着现有观测可以识别所有违规。

强化学习可能利用奖励定义的漏洞；换用 SAC 本身不能消除这一问题。[DeepMind：Specification gaming](https://deepmind.google/blog/specification-gaming-the-flip-side-of-ai-ingenuity/)

## 合法进度与时间

- 不直接按车速表读数、绝对行驶距离或当前位置离起点的距离发放正奖励。用参考路线定位、已核实走廊及有序检查点构建任务进度，检查位移连续性，防止邻近道路或自交位置造成匹配跳跃。
- 在每个前向训练片段中维护最远已确认合法进度；重复经过旧位置不重复领取新增进度奖励。最远进度、任务起点和下一检查点等必要状态纳入观测或明确的奖励状态，避免同一可见驾驶状态隐藏不同评分条件。
- 时间成本按实际有效控制时长计算，不随丢帧或策略调用次数漂移。正式完赛时间由游戏结果与运行日志核验；训练使用的局部任务进度不等于全程成绩。
- 单条参考轨迹不代表道路边界，单靠本车遥测也不代表已获取完整检查点状态。标注、画面或游戏状态尚未核实的区域要标明覆盖范围，不能将估计进度冒充可靠判定。

## 蹭墙与违规识别

初期用已核实的道路/障碍边界、轨迹、侧向运动及诊断录像构建规则检查。加速度突变、侧滑或靠近道路边缘只能提供线索，不能直接等同于碰撞或持续借墙转向；压路肩和偶发接触需要避免误判。

确认违规的真实驾驶片段保留，并给予对应训练反馈；按任务定义可以终止失败片段。疑似违规单独保存前后录像并阻止该结果自动晋升，不能未经核验当作合法纪录，也不能将不确定观测直接标成确定的违规标签。疑似事件可触发少量人工诊断或补充识别覆盖；正常循环无需逐轮人工盯守。

检测能力未覆盖的行为仍可能漏过。第一版先在边界可信的路段学习，逐步补齐全程检查能力；不能把“已写扣分规则”报告成“已经可靠识别蹭墙”。

## 倒带不能抹掉失败

初版驾驶策略只有转向与加减速动作。倒带由独立恢复监督器在已验证的失败条件下操作，设定重试次数和停滞上限；正式评测关闭倒带。一旦发生倒带，该次完整尝试不再具有无倒带完赛资格。

1. 保留导致失败的前向经验、原因与尝试编号。真实驾驶失败按任务失败结算；接口故障另行处理，不能伪装成车辆失误。
2. 倒带动画不进入普通驾驶经验，失败状态不能直接连接或估值到恢复后的好位置。恢复后重建时间、路线及动作历史，开启新的前向片段。
3. 新片段可重新获取其局部练习反馈，这是合法的重复训练；各次反馈不能相加拼成一次完整赛程的进度、回报或成绩。到达终点时仍检查完整尝试的起点、检查点、倒带和人工接管历史。
4. 短段任务成功、倒带恢复后的到达终点、正式全程完赛分别记录。后续若训练恢复决策，单独考虑恢复次数、真实耗时和最终无倒带驾驶能力，不以反复回到好状态本身作为成功奖励。

## 避免通过早撞或拖延获利

单纯每步扣时间、撞毁即结束可能产生提前失败省掉后续扣分的激励。奖励定标必须同时分析进度项、完成项、失败代价、物理时长和折扣，而非任意设置一个大罚分。

每个训练任务明确最长物理时长和无进度期限；设计任务失败的终止回报，使预设反例中故意早撞、临近终点放弃或原地拖延不会胜过正常完成。若使用有限时长任务，其剩余时间应进入观测。真正的任务终止与外部截断分别处理；截断仅在真实最终观测可用时按设计估值，不能拿重置后的状态代替最后状态。[Gymnasium：终止与截断](https://gymnasium.farama.org/tutorials/gymnasium_basics/handling_time_limits/)

这仍是需要实现和验证的奖励设计，不能由几条规则推导出全局无投机保证。

## 正式成绩与版本筛选

先检查完整任务、检查点顺序、无人工接管、无倒带，以及已确认的道路和持续蹭墙规则。确认违规结果无效，疑似违规结果隔离，只有通过有效性检查的结果才比较用时。保留全部尝试，分别报告有效完成、驾驶失败、确认违规、待核验和接口异常；不能过滤掉失败后夸大可靠性，也不能把接口故障直接当成驾驶策略失误。

默认版本优先维持可靠性，再比较速度与平顺程度。激进候选保留合法最快成绩，同时展示失败率，不能因一次很快的有效成绩宣称整体能力更强。正式筛选不采用训练 reward 排名，保留独立最终验收批次。

## 实现时必须通过的反例验证

| 构造行为或记录 | 应验证的结果 |
|---|---|
| 高速驶离目标道路，或绕过检查点走捷径 | 不产生虚假的合法进度和有效成绩 |
| 前进后倒车，再反复通过同一区域 | 同一片段不重复领取新增进度奖励 |
| 路线匹配跳到空间上接近、赛程中更靠后的道路 | 连续性与检查点规则拦截进度跳跃 |
| 持续借墙转弯但用时更短 | 识别已确认时成绩无效，不因圈速更快晋升；识别不确定时隔离 |
| 偶发接触后正常恢复 | 按已定规则记录，不自动等同于持续蹭墙 |
| 失败后反复倒带再到终点 | 保留全部失败，片段分开，不生成无倒带全程成绩 |
| 停车、原地转圈、立即撞毁、终点前撞毁 | 检查整段折扣回报排序及终止逻辑，不能只比较某一步的奖惩 |
| 丢包、菜单切换或恢复导致状态跳变 | 不作为异常高速进步或普通驾驶转移进入学习 |

先用构造记录验证奖励及回合逻辑，再用少量真实驾驶片段检查规则识别能力和误报。未通过时不宣称具备相应防护。

出现奖励上升但行为变差、或可疑晋升时，保留原有效版本并隔离候选，利用轨迹和录像诊断。修改奖励或判定规则后记录新版本，重新评估受影响的成绩，并对相关经验重算奖励或隔离，不能静默混用旧标签。
