# 多模态学习不以精确道路几何为总前置

用户明确要求路线、遥测和真实截图共同进入驾驶策略，以监督初始化后继续自主 RL；T23 的像素感知候选未通过几何/在线门槛，因此将同步可信示范与多模态 BC→SAC 作为主线，精确分割、米制道路和传统控制基线保留为并行研究。此决定补充 [ADR 0001](0001-known-route-first.md) 的已知路线许可，取代“所有学习先等待道路估计合格”的顺序，以动作采集、因果图像历史和可训练表征的管理成本，换取直接验证视觉驾驶的机会；不预断视觉收益或撤销历史负面结果。离线初始化可以先开展，实机合法进度仍需独立局部依据，自动采样仍需控制与重开验证，[恢复分离](0002-separate-driving-and-recovery.md)和[有效性优先](0003-validity-before-performance.md)不变。
