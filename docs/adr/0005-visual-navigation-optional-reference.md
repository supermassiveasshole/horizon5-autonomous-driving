# 视觉导航表达去向，历史参考轨迹可选

为避免驾驶策略永久依赖歌利亚的预录路线，主线允许从真实图像历史隐式学习道路与导航，融合本车状态和因果动作历史，以可选参考航点辅助 BC→SAC；无需先实现专用循迹线提取器。此决定补充 [ADR 0001](0001-known-route-first.md) 的已知路线许可，取代 [ADR 0004](0004-multimodal-learning-before-geometry.md) 中“参考路线为每次 actor 输入必需项”的约定，以增加无参考训练、数据划分和导航条件对照的成本，换取可检验的迁移路径；参考轨迹和独立任务有效性证据继续保留。

首版正式目标仍是歌利亚，可按声明条件使用参考辅助；跨路线和自由驾驶是单独实验方向，不能把接口支持无参考当作已经具备迁移能力。任务奖励与到达判定不由 actor 的视觉特征自证，不强迫轮胎压线，也不在无导航岔路上假定模型知道目的地；旧观测及 #26 验收保留原契约，新契约另行版本化实现，见[视觉导航规格](../design/visual-navigation-spec.md)。
