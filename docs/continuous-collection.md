# 持续被动采集（T35 / #37）

状态：已实现实验入口的数据与存储核心，**尚未实现冻结环境的独立进程启动及 Windows DXGI/UDP/XInput 组合适配器，也未实机采集**。本票保持开放。本切片不要求启动 FH5 或 Steam，不连接虚拟手柄。

## 已有接口

`run_experiment(CollectionRun(...), collection_environment=...)` 接收被动输入流，环境仅有 `read`、`close`，没有发送动作的接口。每次输入可以含原始 UDP 包、带读取/可用时间的原始手柄状态以及已经预处理的数值 RGB 历史。输入配置与已核验的 #27 手柄映射随 session 保存；未校准的映射不能启动。

默认最多采集 4 小时、120 Hz 输入轮询、20 Hz 观测。数值图像默认 480×270 RGB，源分辨率与相机等条件单独记录。当前注入环境用于软件验证；尚不能用该接口证明原生 4K 来源、设备归属或软件运行隔离。

已有文件接口：

```powershell
uv run --locked fh5 collection-status runs/collection-001
uv run --locked fh5 collection-stop runs/collection-001
uv run --locked fh5 collection-review runs/collection-001 --report runs/collection-001-reviewed.html
```

状态查询读取最新心跳或最终状态；停止创建可见请求，采集退出并封存尾块。状态文件单独不能证明进程仍存活，当前接口明确标记 `process_liveness=not_checked`。独立进程的实际句柄与生命周期检查留给下一切片，不用文件存在冒充进程存活。

## 数据与边界

- `session.json` 冻结配置、映射与来源说明；每个封存块绑定它的 SHA-256。
- `.partial/` 是活动块，不供数据集读取。`blocks/000000/` 等目录通过同卷原子重命名封存，包含 `rows.jsonl`、数值 `.rgb` 文件与块清单。
- 块内保留原始遥测包、解码状态、原始与映射后的实体输入、时间和来源。数值帧按内容校验值去重，保存原始整数源时间、处理时间与像素契约。
- 菜单/非活动、失焦、设备断连、竞争输入、车型不符、遥测时钟/位置异常和采集 epoch 变化切断片段。恢复时重建历史；旧帧不能跨边界混入。
- 手柄按实际读取时间核对新鲜度、轮询前进和间隔；新的交付时间不能使旧动作变新。输入值不变但读取时钟前进仍是合法轮询。
- 游戏时钟或位置异常是待核验的重开/倒带候选，不能据此断言完成了一圈。碰撞、离路、导航变化和游戏实际采纳输入也保持待核验。`confirmed_attempts=0` 表示当前核心尚无独立确认来源，不表示用户没有跑过。

当前报告统计活动且输入有效的时长（含起步前静止）、左右转向/RT/LT/滑行的有效轮询数、同步观测、跳过、片段与封存比例。行为轮询数不是独立事件数量。**全部记录的训练资格保持 false**；完整数据块仍需 #38 的质量核验、尝试分组和数据集快照。

## 有界存储与恢复

默认队列最多 256 项，按原始字节及元数据保守预算限制为 128 MiB。源元数据在复制前限制为 64 KiB、深度 8 和 8192 个节点；入队时重新核算完整行、帧元数据和数据字节，不以固定常数替代未知字段大小。元数据核算不执行 JSON 编码，超限明确结束并保留之前封存的数据。另有当前块最多 3600 行/64 MiB，以及封存时的有界编码副本。报告的 `peak_pending_bytes` 只计队列，不代表进程总内存。总数据块预算 64 GiB、最多 4096 块、磁盘预留 2 GiB；少量根目录状态/索引元数据单独存在。

编码、hex、哈希、文件写入及封存在线程旁路完成。队列满时输入继续，所有轮询仍分配单调序号；缺失可由块内/块间序号与最终计数核对。写盘失败、块/数据预算耗尽时受控停止，保留已经封存的块。收尾最多等待 writer 2 秒，未释放会明确记录，不把后台残留当成功。

读取器只验证已封存目录，逐块检查绑定、行数据、序号和数值帧，并核对已有 index/final 中的清单哈希和行数。允许恢复已重命名封存、但尚未来得及写入索引的块。整块通过后才更新跨块统计，损坏块不会污染后续好块。缺少最终状态时尾部损失数量未知，整次记录不算完整；已有最终状态的来源故障与资源释放结果也保留在恢复报告中。哈希是本地完整性核验，不是防止全部文件一致重写的签名。
