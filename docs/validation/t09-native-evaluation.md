## 尚未验证或接入

软件 fixture 不是实际自动重开、真实车辆行为或 4K 性能证据。尚需实机核对菜单模板、起点交接、控制设备切换、GPU 推理和重复短段结果。参考辅助、完成页重开、原生 SAC 和原生 #15 中断恢复仍未交付；已有合成恢复不因此获得原生能力。本增量不能关闭 #4/#9/#10 或宣称驾驶进步。

## 2026-10-03：冻结 SAC 复用原生重复入口

`20a0b55` 补齐上节的原生 SAC 评估软件接点：版本 3 接受 native/mixed CPU SAC，要求非诊断父 BC、同一采集条件和当前候选自己的确定性影子记录。复用已有菜单、数值驾驶和独立审核；探索种子在菜单取得前拒绝。没有新增调度框架，原生自主采样及 #15 学习循环仍未接通。

通过公开实验入口运行真实 CPU BC→SAC 模型、生产线程和回环 UDP，仅外部菜单、摄像头与执行器为模拟设备。两次驾驶之间自动重开，模型及权重不变，每次结束解除输入；独立复审确认两份起跑和执行记录。第二次重开失败保留第一份尝试及未开始槽位，结果不自动晋升。

初始测试在 BC-only 配置门槛失败（`runs/native-sac-evaluation-red.xml`）。接通后还复现已有 BC 经验遗漏：解除输入后 169.2 µs 的首条 BC 决策被当作普通 SAC 转移，预热因量化支持域退化报错。缺图后恢复的公开入口测试独立复现（`runs/bc-supervisor-boundary-red.xml`）。修复仅将监督器后的首条 BC 命令记为 `supervisor_boundary` 并排除，后续正常经验仍实际完成预热及 SAC 更新；未改时间、动作标签、限值或 SAC 自身中立上下文。
