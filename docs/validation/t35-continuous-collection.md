## 已实现与验证

- 实验入口接收被动数值图像、原始遥测与实体输入记录；异步有界归档，分块原子封存，保存配置绑定、像素及清单校验信息。
- 状态/停止/恢复 CLI 可用。核心切片先在同一进程的真实线程中验证采集期间读取已封存块和停止；独立进程证据见下文增量。
- 1200 次合成轮询跨 12 块完整恢复。模拟写盘阻塞时输入继续，队列溢出形成可见缺失序号；预算耗尽或源异常后保留之前封存的块。
- 失焦、设备断连、采集 epoch 改变、车型变化与游戏时钟异常切断片段；恢复后图像不能跨边界。旧手柄轮询不能靠新的交付时间变成新标签，静止且输入不变的正常新轮询仍被保留。
- 来源元数据在复制前有大小和结构上限，入队按完整元数据与原始字节保守核算；1 MiB 扩展字段不能绕过 70 KB 队列预算。数值帧未进入 JPEG 编码路径。
- 损坏块不污染后续完好块的序号与统计；已有索引/最终状态中的清单哈希参与核验。缺少最终状态、未写完的活动块及索引更新前已封存的块均有独立恢复测试，未知尾部不会被判完整。
- 最终状态声明必须与封存数据、错误及资源释放证据一致，不能只修改 `complete` 就掩盖失败。恢复报告保留源异常与归档异常原因。

以上均由 `run_experiment` 验证，输入为合成数据。没有证明 4K 游戏性能、原生设备归属、持续多圈采集质量或训练收益；所有原记录的训练资格保持 false，等待 #38 按用途核验。

## 独立进程与原生组合的软件增量

- 合成 bundle `runs/t37-synthetic-reviewed-20260930/` 在另一个工具调用结束后保持运行。全套测试并行期间采集 45 秒，封存 84 块、4992 条记录，无丢失；828 个观测可同步。运行中读取并验证 25 块、1500 条记录，活动尾块保持不可用。最终恢复 84/84 块，完整且资源已释放。此次停止命令到达时已自然到时，不能把它记作主动停止证据；主动停止另有进程测试。
- Windows 启动器 PID 与真实 worker PID 分别记录。状态按启动 token/digest 关联真实 worker，再向 OS 核对 PID/创建时间；终止合成 worker 后可发现异常退出并恢复封存块。父核验后文件变动，子进程拒绝启动，并正确报告失败和未通过核验。
- 被动原生组合接入 DXGI 数值帧、UDP、已校准 XInput 逻辑身份及资源监测，没有虚拟控制器接口。合成适配测试验证设备失配/断连隔离、恢复后重建历史、并发采集器争用与 OS 锁释放。UDP 独占绑定及合作采集器锁不代表能排除任意第三方程序；真实设备语义仍待游戏核验。
