2026-10-01。通过既定 `run_experiment` / CLI 入口验证可选临时模仿损失、冻结开发协议、阶段审核和状态恢复。使用真实 CPU Torch 更新与明确声明的合成环境；未启动 FH5/Steam、原生采集或真实控制设备。整票保持开放。

## 学习与评估

临时损失在当前采样观测上比较原始冻结 BC 和 SAC 的确定性命令，按同一可执行区间归一化。教师、critic/encoder 与 actor 的梯度职责分别保持；历史线路和速度没有成为永久监督目标。纯 SAC 默认行为不变；显式零约束产生相同学习状态和预测，不再调用教师计算约束。

训练前固定开发评估协议，每轮重新核验源记录、模型摘要、完整尝试、实际网络执行、起跑及独立有效性依据。合成环境中的合法性、可靠性、用时达到预设门槛后，一次最多降低一个阶段。训练回报、更新步数或手填通过标志不能触发退出；最终验收批次不用于调整系数。

保留原型 `runs/t10-imitation-20261001/`：

1. 实际训练 30 次，随后固定候选。两轮开发评估分别有两次原始 BC 和两次 SAC 执行，且使用新登记的记录。
2. 网络输出实际驱动一个三米直道的外部合成环境，速度随转向幅度变化。两轮候选均达到该夹具的预设局部门槛，系数依次从 **1 → 0.5 → 0**。这套动力学用于验证软件路径，不代表 FH5 或真实赛车物理。
3. 零步阶段审核没有改变学习器、优化器或 RNG。退出后继续更新 5 次，累计 **35** 次，教师约束调用为零。
4. 独立 Python 进程重新加载最终检查点，预测与保存前完全相同；证据位于 `new-process-verification.json`。

用途库与原始录制摘要仅检查已登记来源的重用，无法证明未登记或变换后的全部训练历史独立。当前门槛明确为 `synthetic_development_only`，默认驾驶版本不变，也不把这套夹具中的提速解释为 FH5 驾驶改善。
