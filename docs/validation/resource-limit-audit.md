## 过度工程化复审的行为修复（2026-10-04）

本次按用户指出的五项处理；这些门槛早于目录重组，不将它们描述成本轮新引入。

| 项目 | 当前行为与验证 |
|---|---|
| 决策暂时不可用 | 普通缺图、忙碌、迟到进入中立等待，合格观测恢复后继续；旧动作仍按原绝对期限过期。此前 `runs/neutral-wait-focused.xml` 的 73 项验证，实机时效另验 |
| 采集与准备增长 | 默认块数和总磁盘预算为 `None`，额外磁盘预留为 `0`；显式实验预算及实际空间检查保留。封存引用使用追加日志与摘要绑定前缀，兼容旧数组。移除 100 来源、1000 尝试/区间、1000 万序号与审核 4 MiB 上限，嵌套审核按磁盘索引读取 |
| 必要记录与展示 | 实时报告大小不改变精确回放资格，先流式封存必要 JSON 和摘要，再计算可重建统计及 HTML。可选展示的资源故障降级，统计中断后仍能精确回放；必要封存失败仍明确报错 |
| 训练资源压力 | 内存/磁盘准入压力使用已有暂停、释放、等待和恢复路径。显式等待/总时长预算耗尽或主动停止仍保存进度后结束；真实 CPU 的连续 6 步与暂停后 2＋4 步模型、Adam、随机状态一致 |

Spec 复审曾指出可选统计早于必要封存。公开中断反例先失败，调整顺序并把显示派生字段移入副本后通过；相邻七模块 119 项通过（`runs/realtime-seal-before-metrics-final.xml`）。固定 `5f7ec82...5c6e571`、`5c6e571...991dade`、`991dade...2776587` 分段完成 Standards/Spec 审查，最终无确认遗留；块写入部分的 Spec 核对为作者自查，其余由不同实现者交叉检查。

组、覆盖率和范围摘要仍随尝试数增长；队列默认值及其他未审限制未因此获得依据。未运行 FH5、原生截屏/控制器或 CUDA，软件回归不替代实机验收。

## 已完成的结构迁移

这些是已核验的软件行为，不表示所有消费者都已改为固定内存。

| 范围 | 当前结构与保留约束 |
|---|---|
| learner、权重与祖先历史 | 私有副本核验后加载；流式哈希/复制，祖先按摘要关联独立节点，兼容旧数组。模型、优化器、随机状态与实际更新额度仍核对 |
| 原件、经验与容量清单 | 逐件校验/复制，磁盘索引承载路径去重、转移与角色；按需构造批次。已迁移入口不再以累计帧字节数、来源数或清单大小拒绝正常增长 |
| SAC / critic / BC 诊断 | 逐步 loss、预测与阶段历史使用可选日志；独立数值摘要保留模型重载核验，展示失败不替代必要完整性检查 |
| CPU BC 恢复 | 完整优化器更新边界保存 learner；连续 6 步与停止后 2＋4 步的模型、Adam、随机状态相同。未承诺强杀或半次 Adam 更新恢复 |
| 采集控制和冻结安装 | 状态按字段投影，完整 session 与进程绑定仍核验；Windows 控制文件共享读取与专用发布配合。v3 包独立安装，每轮使用新输出目录 |
| 配置、图像与参考路线 | 严格流式配置读取；像素按实际布局与字节数核对；参考资产逐件绑定、流式复制。合法控制域、来源身份、时间因果及 train/eval 独立性继续校验 |

操作契约分别见[持续采集](../guides/capture/continuous-collection.md)、[数据准备](../guides/bc/collection-datasets.md)、[训练与恢复](../guides/bc/training.md)、[学习存储](../guides/sac/learning-storage.md)和[连续循环](../guides/sac/learning-loop.md)。

## 尚未完成的审计与实机验收

- 采集/推理队列、单块大小和源元数据限制仍需说明测量依据与退让策略。组、覆盖统计、范围摘要及部分目录/文件清单仍随数据增长，不能宣称整个系统固定内存。
- 同步采样、循环轮次/尝试历史、实时经验的决策/命令及累计像素、被动探针等其他入口仍需逐项审计；本轮没有证明所有预算外拒绝已经清零。
- 全排列抽样、单个未投影嵌套记录、整份路线几何/组元数据，以及返回普通列表的旧读取接口仍可能占用随数据增长的内存。
- 原生 Torch/优化器中途内存故障、进程强杀、未封存的部分输出和永久阻塞的外部驱动调用不在完整更新边界恢复的保证内。真实 I/O 耗尽及完整性损坏仍明确报错，保留既有成果。
- 真实 4K 捕获、两次人工驾驶及重开、游戏共享负载、冻结候选的只读时效、短段车辆响应与自主学习收益尚待实机证据；软件回归与合成 native 适配器测试不关闭这些验收。

显式时长、等待、更新及磁盘预算继续生效；来源绑定、控制归属、时间顺序、独立分组和外部协议合法域不能随容量清理取消。
