## 行为与证据

通过已约定的 `run_experiment` / CLI 入口，以真实 Torch 加载冻结数值 Δt BC，对合成环境的完整输入逐条重放预测；检查运行配置、来源、遥测状态、安全状态、参考模式、命令幅度、期限和最终解除输入。

- 普通数值 actor 与匹配契约的影子适配器均可得到 `bound_diagnostic`；这不是实机驾驶证据。
- 不相关包流、模型/运行配置/图像/日志/参考模式不符、缺存档、错误发送值、安全时钟不一致或缺末尾解除输入，均隔离执行指标；所有尝试保留。
- 原局部成功如绑定了不匹配的执行凭据，转为本批待核验；不贡献有效用时，保留原局部结论。
- 从原始时间线重新计算有效决策率、连续跳过、画面年龄、已记录视觉比例、控制权时长和转向变化，忽略来源报告中预先汇总的指标。运行只计一次，批次频率按总次数除以总时长。
- hold 采用成功发送返回时刻作为代理；跳过时刻的图像可用性可能未知。两者均不能替代真实游戏动作响应或 DXGI 丢帧测量。

原型目录 `runs/t09-execution-20261001/` 包含四种场景：`bound` 与 `shadow-adapter` 通过诊断绑定，`archive-gap` 与 `reference-mismatch` 被隔离，每种场景均保留一条尝试。`prototype.json` 保存检查结果，各场景 `review/report.html` 保存报告。该影子适配器原型仍使用合成外部环境；未启动游戏、Steam、截图、UDP/XInput 或虚拟手柄。
