2026-10-02。在 `RealtimeRun` 与已有 SAC learner 之间增加 `SACRealtimePrepare`，
通过约定的 `run_experiment` 边界验证。FH5、Steam、原生截图、游戏 UDP、手柄与 CUDA 均未启动。
模型使用实际小型 CPU BC/SAC，模拟的是外部观测、遥测及命令接收；不能据此宣称实机驾驶或能力改善。

## 行为和证据

异步记录保留成功发送命令、实际持有时间、独立任务反馈和可恢复的数值 RGB。
下一状态的动作区间使用下一决策当时已知的经过时间，而非包含未来发送延迟的完整 hold。
测试追加准备好的经验，实际运行两次 SAC 更新，检查累计步数、critic 变化及父快照不变。
仅改变下一命令在决策之后的返回延迟，重新训练得到相同 learner 状态摘要。

同一边界还覆盖：

- 单份图像缺失只排除相关转移，其他完整片段保留。
- 确认的驾驶失败保留终止惩罚；无末观测的截断不生成假失败。
- 异步经验初始化后可再追加旧同步经验，各自时间语义保留。
- 独立恢复边界拒绝沿用旧 epoch/历史。
- 图像缺口触发监督器释放，其间不生成策略转移，之后完整片段仍可接纳。
- 缺少独立核验覆盖时不产生可学习的合法进度奖励。
- 已发送命令与合成遥测反馈不一致时排除转移；不把发送函数成功视为应用证据。
- 准备期间执行清单被外部文件修改时拒绝封存，不让旧转移冒用新来源摘要。

RED/GREEN 已验证：异步来源初始化后的混合被旧版本检查误拒绝，修复后通过；恢复边界误收旧 epoch
已复现并修复。整合专项回归 **139 passed / 160.98 秒**：异步经验/探索、SAC 预热/学习/续训/混合/循环、
执行绑定、实时数值重放与 Δt BC。证据为 `runs/t10-async-regression-20261002-results.xml` 及同名测试目录。
包含 CPU 线程数重载断言修复；[原全量失败与诊断](temporal-bc-cpu-roundoff.md)单独保留。
当前增量的整库回归与只读审查尚待完成。

## 审查修正

固定 `4a3c3d3...480ec64`：Standards 没有文档规范违反，指出一处奖励准备/聚合逻辑重复；
已抽取 `sac_rewards.py` 供同步和异步转换共用，动作时间与观测资格仍由各适配器负责。
Spec 指出缺少合成命令反馈核对、执行来源可能在准备期间替换两项问题。
分别新增公开实验入口反例，先复现误收经验和未拒绝替换，再修正；没有模拟内部模型或检查函数。
反馈修正后异步测试 **8 passed / 16.28 秒**，来源替换专项 **1 passed / 4.10 秒**。
修正与抽取后的回归为 **140 passed, 1 failed / 163.40 秒**；唯一失败来自合成断图测试的墙钟竞态：
固定 170 ms 缺图加调度延迟有时先触发无决策 watchdog，使测试尚未进入预期的恢复后经验断言。
改为外部适配器收到实际解除命令后恢复供图，运行器的 100 ms 动作租期与停止时限不变。
最终异步文件 **9 passed / 17.73 秒**；其余 132 项已在前一回归通过，未改相应实现。
证据为 `runs/t10-async-reviewed-regression-20261002-results.xml` 和
`runs/t10-async-reviewed-final-20261002-results.xml`。复审与整库回归结果另行记录。
