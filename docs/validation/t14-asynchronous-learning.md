# T14：异步采样接入连续学习循环

日期：2026-10-02。GitHub #15 的软件增量，基于 `62f8c1b`。
FH5、Steam、原生截图、游戏 UDP、手柄和 CUDA 均未启动；整票保持开放。

## 实现与可观察行为

`LearningLoop` 配置版本 3 使用既有异步数值运行器采样，再依次进行经验准备、实际 SAC 更新、
冻结评估和候选保存。每次采样释放后才进入学习；下一轮使用新探索版，未通过独立资格的候选不会
替换可靠默认。版本 1/2 的同步输入和更新规则保留。

每轮更新额度为合格新转移数与 `max_updates` 的较小值，分别报告经验数与更新预算。
停止后显式接续只补原预算内的剩余更新，不因存在更多经验就自动追加训练。

子任务已封存、父状态尚未登记时，恢复核验原始执行清单、命令/遥测账本、数值图像、独立依据、
冻结配置及完整 learner。已封存零更新发送失败可按配置有限重试，保留原失败和新尝试的独立目录。

## 验证进度

通过既定 `run_experiment` 入口运行实际小型 CPU BC/SAC。只替换外部游戏、菜单、图像和文件故障；
未替换策略、学习器、奖励与恢复校验。合成外部响应不模拟 FH5 的真实车辆动力学。

- 两轮循环：配置版本 3 尚不支持时先复现失败；实现后实际完成四次更新、两轮冻结评估与保存，
  下一轮使用上一轮模型，可靠默认保持原样。单项 **1 passed / 188.34 秒**。
- 封存后进程退出：先复现同步恢复协议错误，再支持异步原件核验。保留停止标记时不取得环境，
  解除后只补两次更新并评估，不重新采样，原始文件不变。单项 **1 passed / 158.03 秒**。
- 首次发送失败：记录并释放首轮，限次重新采样，实际完成两次更新和评估，失败没有获得更新额度。
  单项 **1 passed / 142.25 秒**。
- 完整新模块回归正在进行，另覆盖遗漏数值原件的拒绝，以及同步版本兼容。
- Ruff lint、格式、mypy 128 源文件和 diff 检查通过；双轴审查待完成。

首次循环验证曾因测试数据与候选选择共用 `record.json` 路径而失败；分离 fixture 目录后通过。
该失败是测试准备错误，不能当作实现已通过或实机反馈。
