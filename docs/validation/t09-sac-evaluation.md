# T09 / #10：冻结 SAC 的重复评估与命令上下文

2026-10-01。本切片在已有冻结 BC 批次上增加显式 SAC 模型类型，以实际 CPU Torch 推理验证重复执行、完整尝试保留及离线动作复现。环境是响应动作的合成夹具，不是 FH5 物理模拟；未启动 FH5/Steam、原生采集、游戏 UDP/XInput 或虚拟手柄。#10 仍开放，不能据此声称真实驾驶或驾驶改善。

## 实现边界

配置版本 2 冻结 `policy.json`、`policy.pt`、训练报告与 BC 归一化/历史元数据。实际编码器和策略来自 SAC 检查点，关闭探索，冻结批次不更新权重。评估副本可搬迁并独立重载，但不包含完整经验，不作为续训包。操作与限制见[冻结评估说明](../evaluation.md)。

SAC 每次决策额外记录最近一次成功发送命令及其返回时刻；经过时间使用主机代理，不能解释为游戏实际应用时刻。首次就绪先确认中立命令成功，再运行策略。推理期间租期解除输入后，旧上下文结果不再发送。数值回放和批次审核分别验证预测及命令来源；可复现的预测不自动等于有效执行证据。

## 保留原型

`runs/t09-sac-evaluation-20261001/` 保存 `prototype-summary.json`、两种批次、全部命令/像素/包流及新 Python 进程的 `cli-replay.html` / `cli-replay.log`。

- 响应动作的环境运行两次各 0.7 秒，独立审核均绑定成功，各复现 12 个预测。两个终点分别约为 0.3373、0.3376 米，证明后续输入响应实际输出；不以此比较策略强弱。
- 第二轮重开无法确认时，只保留第一轮已开始尝试，第二轮明确未开始；已开始回合仍可回放，不伪造成功重开。
- 原模型字节保持不变，资源释放确认，命令行新进程回放成功。所有结果均为诊断，自动晋升保持关闭。

## 故障与回归

10 项新增公开入口测试覆盖冻结包搬迁、两轮 SAC 执行、训练/执行幅度不兼容、租期期间上下文变化、首次中立发送失败、伪造未发送命令上下文、独立用途登记、模型替换、CLI 回放，以及可回放但发送前已解除输入的反例。旧 BC 接口与命令优先审核顺序保留。

最终专项回归 **30 passed / 64.64s**；审查修复后运行一次完整回归，**862 passed / 557.56s**。mypy 检查 100 个源文件通过，Ruff lint 与 238 个文件格式检查通过，`git diff --check` 通过。修复过程中曾因审核顺序改变而使旧 BC 的错误原因断言失败；恢复既有命令优先顺序后，专项与全量均通过。

## Standards

基点 `b645bf7`。初审无硬规范违反，发现 1 项 P3：SAC 被普通数值 actor 接口接纳却拒绝其 `predict`。`fc02120` 分离元数据、普通预测与上下文预测协议，实时入口接受明确联合类型，普通推理入口提前拒绝上下文 actor。独立复审无遗留可操作问题。

## Spec

初审发现 1 项 P2：审核只验证决策开始时的上下文，遗漏发送前可能出现的解除输入。公开入口反例先失败；`ef77196` 增加发送前最近成功命令的独立核对，复审确认受影响执行被隔离、预测仍可回放、全部尝试保留，另一轮正常记录仍可用。`122f513` 保留既有命令优先审核顺序，独立复审确认两项上下文核验均继续执行，Spec 遗留为 0。Standards 对接口与证据修复的复审也为 0。
