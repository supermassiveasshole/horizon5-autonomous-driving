# 驾驶 HUD 识别修复与实机重开（2026-09-29）

关联 Issue #4（T03），代码基点为 `6bcc171e49f46bde9590fa3af5e54b7e85a81472`。本轮修复驾驶页模板对场景亮度和圈数变化的敏感性，完成一次新的静止重开循环。T03 仍开放，`conditions_verified` 与 `unattended_verified` 均为 false。

## 复现与原因

[第二次人工整圈](human-goliath-02.md) 的最终驾驶段有 997 帧，采集时旧分类器全部判为 `unknown`。从原始记录提取第 600 帧，以原冻结配置运行本地 `.scratch/driving-hud-diagnosis/repro.py`，连续两次复现失败。

画面尺寸和 HUD 位置没有变化；旧模板包含起跑时的“0/1”和明亮背景，实际行驶变为“1/1”，且半透明文字背后的场景不断变化。该帧两块旧模板的 MAE 分别为 0.44763、0.26506，超过阈值 0.045；没有其他页面同时命中。强光还会使左上角白色文字失去对比度，因此仅调整亮度归一化不足以解决问题。

## 实现与校准

模板新增显式可选的 `metric: "gradient"`：用带符号的横向、纵向相邻像素差比较结构，误差为 `(1 - 余弦相似度) / 2`。旧配置默认仍为 `mae`。纯色模板、未知方法在发送输入前拒绝；纯色观测、反色和不同结构不匹配。多图块同时命中、跨页面歧义拒绝、连续两帧、车型/起点核验和所有停止保护保持不变。

先通过实验运行入口建立亮度变化导致起跑失败的回归，再实现修复；非法方法与纯色模板检查同样先复现失败。行为测试覆盖成功起跑/重开、回放一致性、反色、错误结构和无特征画面，不直接断言私有识别函数。

本机最终配置为忽略目录中的 `runs/t03-menu-profile-v5/config.json`，以人工记录第 600 帧的左下固定 HUD 文字制作两块模板：640×360 灰度画面中的 `[37,334,58,342]`、`[70,334,91,342]`，阈值均为 0.075（余弦相似度至少 0.85）。其他菜单模板及阈值未改。配置 SHA-256：`3fa0dadfd74938edb4a0a75ea99326cc9ef30546f6fc750862b8a9c5e6b4d1ce`。

早期 v3/v4 是已弃用的亮度归一化原型，分别只识别最终驾驶段的 815/997、512/997 帧，不作为可用配置。诊断过程中原留出帧已被查看和用于调整，整份人工记录因此属于校准材料；分析文件中历史 `holdout` 字段不代表独立测试集。

最终冻结配置的离线检查：

|---|---|---|

## 冻结后的新实机验证

两轮均使用真实 `fh5 event --live` 与 Xbox 菜单适配器；只发送菜单按钮，不发送油门、刹车或转向。固定蓝图 `105657219`、第六元素特别版 X 999、原调校与辅助条件沿用。每次尝试限时 5 秒，最多两次，准备/重开各限时 30 秒。两轮间只改变初始菜单步骤，不修改识别模板、阈值或停止保护。

### 首轮：成绩页重开时保护停止

`runs/t03-hud-gradient-live-01/` 从成绩页识别 `finish → confirm` 并发送 `X → A`。收包跨度 1.7636 秒，113 个有效包，其中 6 个活动包；9 帧中完成页和确认页各 2 帧，其余未知。尚未创建驾驶尝试即以 `probe_vehicle_moving_or_input` 停止，释放调用成功。

活动样本 `packet_index=107` 出现 `accel=255, brake=0, steer=127`，当时速度约 0.01268 km/h，相邻活动包的驾驶输入为零。用户说明：“停止之前我们有切画面，一点重新开始就停止了。”这说明观察到的时序，未确定异常输入来自人工、切换瞬态还是其他来源；不能据此宣称满油门驾驶或保护误报。保留原始失败记录，没有增加忽略该样本的例外。成绩页到下一轮的完整恢复仍未通过本轮实机验证。

### 第二轮：暂停菜单开始的两次静止起跑

重新观察到游戏位于世界地图选中的赛事暂停菜单，因此以 `live-from-pause.json` 启动。运行期间没有 Computer Use 干预，程序执行 `RIGHT → DOWN → A → A → A` 完成初始重开，然后按原重开步骤再执行一轮。

- `runs/t03-hud-gradient-live-02/` 收包跨度 **36.5545 秒**，2,075 个包全部有效，其中 893 个活动包；车型/PI 均为 2941/999，所有活动包驾驶输入为零，峰值约 0.00211 km/h。
- 两次起跑有独立尝试标识，中间记录一次 `recovery_verified`。`prepare → started` 为 **12.7035 秒**，`restart → started` 为 **13.7917 秒**；两次起点与锚点距离约 0.00424 米，仅支持返回同一起点，不代表定位精度。
- 保存 199 帧：63 帧 `driving`，116 帧 `unknown`，其余为已知菜单各 4 帧。过场和未知帧保留未知，没有放宽阈值追求全帧命中。
- 两次均按预设记为 `failed / attempt_timeout`，最终 `attempt_limit`，退出码 0，释放调用成功。退出后观察到游戏在暂停菜单并显示手柄断连提示；没有继续驾驶。

这份新采样支持冻结模板在静止起跑和菜单循环中的可用性，不覆盖新一圈移动中的画面变化、真实驾驶失败恢复或长期无人值守。
