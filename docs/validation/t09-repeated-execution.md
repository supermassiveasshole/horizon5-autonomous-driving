# T09 / #10：重复执行与起点交接验证

2026-10-01。通过既定实验入口实现 `EvaluationRun` 的首个可运行重复批次，串联已存在的事件识别、真实 Torch 冻结 actor、实时数值录制和全部尝试评估。环境输入为合成数据；没有启动 FH5、Steam、截图、UDP/XInput 或虚拟手柄。#10 保持开放。

## 已验证行为

- 开始配方确认起点后运行一段，再执行重开配方并运行下一段；菜单环境先关闭，策略环境后打开，各段使用独立 actor 与空动作历史，冻结权重保持不变。
- 画面、车型、PI、位置和停车状态参与准备确认；遥测和画面须晚于最后一次菜单动作。策略接收端重新核对位置、向前游戏时钟及中立踏板，交接状态变化时不发送非零策略命令。
- 重开不确认则保留第一段、将下一槽位列为未开始；驱动打开失败保留接口尝试。父环境关闭报错也生成报告，明确资源未释放。
- 冻结模型或菜单配方改变时停止后续尝试；无法回放的冻结资产保留错误及原清单，不伪造评估结果。

当前合成车辆观测是静止状态，用来核验真实模型的命令和资源交接，没有动力学或驾驶能力结论。当前运行器仅支持 1–10 次无参考批次；成功执行协议不等于局部驾驶有效，报告继续禁止晋升。
