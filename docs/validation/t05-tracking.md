## 软件行为与证据

通过已约定的 `run_experiment` 入口传入配置和外部合成车辆。测试环境独立实现带转向滞后、阻力和不同轴距的运动响应，不读取控制器内部状态；它不是已标定的 FH5 模拟器。路线与矩形试验区域明确标记合成来源，不能作为真实走廊依据。

冻结示例位于忽略的 `runs/t05-tracking-20260930-reviewed/`，各目录包含完整遥测、实际命令、路线资产、初始报告与独立回放；`audit.json` 保存原始包和命令 SHA-256。初版 `runs/t05-tracking-20260930-software/` 同样保留，不覆写。

四组都记录了最终归零调用；独立回放的样本、路线与结果完全一致。直线回归还移动原路线清单，证明回放使用随记录封存的依赖。命令关联当时已收到的原始包，并核对观测接收时间 ≤ 下发调用开始 ≤ 下发返回；这证明软件的因果记录，不证明 FH5 实际采用输入的延迟。

行为测试另覆盖无进度、初始等待超时、非静止起步、中间包异常后跟随正常包、失焦、F8、看门狗故障、暂停、车型变化、超速、侧偏/朝向超限、时间倒退、坏包、无效运动字段、未来时间戳、断流、游戏时钟停滞、调度/发送阻塞、发送/归零/关闭错误，以及配置越界。失败保留结果和最后位置，命令失败不填造成功值。

报告复用已有轨迹、速度、定位与命令展示。本轮未声称浏览器交互验收；合成报告不能代替真实驾驶视频或游戏中反应检查。

## 真实验收仍缺什么

1. 独立核实包含连续弯道的短段可行驶区域与检查点。现有拱门后约 19.55 米范围只支持已有局部几何结论，不能据此宣称弯道已覆盖。
2. 在第六元素特别版、原调校、固定蓝图条件下实跑，核对实际转向、速度、轨迹、碰撞/离路和完整失败记录。候选反馈参数尚未标定，0.25 油门可能不足以维持真实速度。
3. 同步独立画面核对动作与道路效果；若作为多模态 BC 示范，另按现行数值图像和动作对齐契约验收，本票当前不直接产出该训练数据集。
4. 验证真实小偏差恢复与限时停止；当前无法正常救回时仅停止，不调用尚未验收的自动倒带/重开。

`game_response_validation=unverified`、`formal_validity=pending_independent_review`、`sustained_sampling_allowed=false` 保持不变。无倒带完赛、无人值守和学习收益仍由相应后续任务独立验收。

### Spec

初审发现 2 项 P2，均由实验入口回归先复现再修复：斜向检查点尚未通过时，仅投影达到停车区会误报 `local_end`；现要求连续确认进度抵达目标，否则记 `unconfirmed_target`。另一个是失焦后关闭设备失败覆盖原停止原因；现在保留 `prior_stop_reason`，并独立记录 `close_error`。真实连续弯道和实际动作响应仍是明确未完成的验收项。
