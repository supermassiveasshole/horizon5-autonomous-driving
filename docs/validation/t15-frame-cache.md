# T15 / #16：按字节限制的数值帧热缓存

日期：2026-10-01。分支 `codex/learning-frame-cache`，基于主分支 `22dcd2c`。本增量在隔离工作树开发，不修改正在执行全套回归的主分支源代码。没有运行 FH5、Steam、原生捕获或控制器；#16 保持开放。

## 行为与证据边界

学习用帧以摘要共享、以 uint8 常驻；历史和转移持有稳定引用，按 LRU 淘汰内存，冷数值文件保留。训练、续训和冻结回放支持显式字节预算；新候选继承预算，旧候选保留默认兼容。批次直接复制为浮点输入，避免历史引用阻止旧缓存帧释放。命中、缺页重载、淘汰和峰值可见；不缓存可训练 encoder 的旧 latent。

验证仍通过公开 `run_experiment` / CLI。使用实际保留 learner，新增不同颜色的合成数值帧后通过 `SACReplayPrepare`、零更新 `SACResume` 建立合法候选；不直接改模型或内部审核返回值。文件损坏由外部文件系统写入边界注入。以下原型不执行新梯度更新：

| 场景 | 结果 | 本地原件 |
|---|---|---|
| 共享帧与显式一帧预算 | RED 不支持请求字段；GREEN 6912 字节缓存内共享相同帧，预测不变 | `runs/t15-frame-cache-{red,green}-20261001/` |
| 五种数值帧、一帧常驻预算 | RED 原全量留存超过预算；GREEN 有可见淘汰/重载，峰值 6912 字节，与大缓存预测逐项相同，源文件不变 | `runs/t15-frame-cache-eviction-{red,green}-20261001/` |
| 只改变续训缓存预算 | RED 不支持续训字段；GREEN 零更新完整 learner 摘要与预测不变，重载继承预算 | `runs/t15-frame-cache-resume-{red,green}-20261001/` |
| CLI 选择预算 | RED 未知参数；GREEN 可运行并报告预算 | `runs/t15-frame-cache-cli-{red,green}-20261001/` |
| 首次预测后冷文件内容改变 | 后续重载核验失败，不发布候选清单 | `runs/t15-frame-cache-cold-tamper-20261001/` |
| 零、布尔值和不足一帧的预算 | 拒绝并不发布回放报告 | `runs/t15-frame-cache-{zero,bool,too-small}-20261001/` |
