## 软件行为

`tests/test_numeric_images.py` 经实验运行入口覆盖：

- 生产者改写共享 buffer 后，actor 与存档仍得到发布时像素；真实冻结 BC 的数值预测与旧离线预测在容差内一致。
- 执行期间禁止压缩图像编解码；像素文件读取和哈希限定在数值源/存档线程，模型只接收数值帧。
- 不可用未来帧、跨 epoch、重复帧、缺失历史、年龄不符、尺寸/缩放/源布局变化不调用模型。
- 存档延迟、字节/任务限额、写入失败不会改写预测；无法保存的输入明确不可回放。源/模型失败保存已完成结果，停止限额不多取下一帧。
- 数值文件缺失/损坏、汇总与输入不一致、资产路径越界被拒绝；展示图删除、改变或写入失败不改变数值预测。
- 已绑定源日志、示范 manifest 或历史边界改变时拒绝准备；示范动作与未来监督数据单独留存，均不进入 actor。

审查修复后全套 **392 项 pytest 通过**（含 33 项数值接口测试）；严格 mypy、ruff lint、格式及 diff 空白检查通过。由于审查抽取了共享历史边界逻辑，修复后重新运行全套，而非仅依赖新增测试。
