## 范围与软件证据

- `RecordUsage` 经实验入口登记完整录制的训练／选择用途，输出原文件指纹、登记快照和报告。SQLite 事务及幂等键保留历史。
- 批次准备可绑定登记库身份并预登记冻结摘要；审核及合成重复执行自动登记评估用途。时间元数据未知、异常、未开始槽位、空数据及库缺失不构成独立性通过。
- 已知训练重叠、后来用于选择、修改会话注释后复用包流、另一最终批次重复使用，均保留冲突。重复审核同一批次不会重复记账，后续用途仍会使新的审核发现冲突。
- 独立性不替换局部驾驶统计；库不可读时仍生成全部尝试报告。命令行区分输入故障与独立性资格不足。
- 审查发现同批次槽位换样可隐藏旧失败后，已增加持久的槽位／原始录制绑定：替换或删掉已审核失败会拒绝新报告；未开始槽位仍能补齐。两类反例均先复现失败再修复。

`no_known_overlap` 不等于已证明独立。尚未把现有训练入口全部自动接入，也没有证明历史使用登记完整；指纹不能识别任意变换后的复本。报告继续禁止晋升。
