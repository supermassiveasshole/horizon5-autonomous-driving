# T14 / #15：保留失败的有限重采样

日期：2026-10-01。隔离分支 `codex/learning-sampling-retry`，基于资源监测分支 `3217989`。#15 保持开放；未启动 FH5、Steam、原生捕获或控制器。

## 本轮行为

可选 `sampling_retry.max_retries` 限 0–3，按每轮累计，显式接续不刷新额度。已封存、资源释放明确、零更新且无候选输出的失败才能开启新尝试；失败目录和摘要、原件及外部审阅依赖保留。用户停止不会自行重试，之后显式接续可在同一额度内继续。正常候选一旦训练完成，继续进入冻结评估，不因前次失败重复更新。

这不恢复强杀后的未封存阶段，不重新采纳部分写出的候选，不重跑已经失败的评估。当前仅支持已有合成学习入口。

## 已执行证据

公开 `run_experiment` / `LearningContinue` 入口使用实际保留 learner 和独立可写版本库副本。发送失败、停止文件、部分写出目录及释放失败由外部环境/文件系统注入，不替换网络、训练或验证结果。最初六组原型未启动新训练；审查后的子任务停止反例实际触发了本应禁止的 3 次更新和 2 次评估，修复后没有更新。
