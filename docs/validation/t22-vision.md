# T22 彩色采集与回放验证

2026-09-29；关联 GitHub #23。在 `63c5a2c` 之后实现并分阶段实测，运行清单保存各阶段 Python 源码哈希。首轮记录区分中间版本驾驶与优化版菜单结果；后续增加了提交 `a2dee87` 的最终版真实驾驶复测。

## 软件行为

新增 `fh5 vision`，通过 `run_experiment(VisionRecord(...), vision_environment=...)` 记录，沿用 `Replay` 回放。测试从实验入口覆盖在线因果配对、未来包隔离、失焦/坏包/暂停/重开/断流、缺失与过旧观测、延迟交付、容量停止、异常中断、损坏日志和图片、loopback UDP、采集器故障与资源释放。历史纯遥测、控制、赛事和路线测试继续通过。

最终全量 156 项测试通过，其中新增视觉行为用例 20 项；严格类型检查、Ruff lint/format、Git 空白检查通过。

MSS/Pillow 仅由实机适配器延迟加载；没有创建虚拟控制器或发送菜单/驾驶输入。短复测时通过 Computer Use 将 FH5 置前，停留在原暂停菜单。回放图片已直接抽查；HTML 脚本通过 `node --check`。G 盘记录生成 C 盘临时报告也已实跑，图片引用采用 `file:///G:/...`。这些检查不等同于浏览器页面播放交互验收。
