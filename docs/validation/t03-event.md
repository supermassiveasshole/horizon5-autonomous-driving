## 2026-09-28 实机菜单与遥测验证

沿用 `configs/goliath-458574769.json`，只通过 Computer Use 操作菜单，不发送油门、刹车或转向。用户手动打开暂停菜单；其余操作逐步观察页面后执行。第一次鼠标点击未按预期选中重开，而进入地图；返回后使用方向键逐项核对选择，未退出赛事。

已观察到的流程：暂停菜单世界地图选中 → 右（退出赛事选中）→ 下（重新开始赛事选中）→ Enter → “重新开始赛事”确认框、“是”选中 → Enter → 加载 → 歌利亚赛前页、“开始赛事”选中 → Enter → 单车起点 HUD。按钮顺序依赖上述初始选中状态，不能作为任意菜单位置的盲按脚本。

本地画面位于 `runs/t03-conditions-20260928/`：`blueprint-grid.jpg`、`blueprint-start.jpg`、`blueprint-pause.jpg`、`blueprint-restart-selected.jpg`、`blueprint-restart-confirm.jpg`、`blueprint-restart-ready.jpg`、`blueprint-restarted.jpg`。最后一张包含桌面通知遮挡，不能直接用作干净的完整 HUD 模板。

## 尚缺实机证据与实现

- 实际季节，以及时间/天气重开一致性；当前季节选项未固定。
- Windows 画面与菜单输入适配器，以及真实页面模板的正反例校准。
- 真实完成页面及暂停、退赛、恢复位置变化等反例。
- 程序独立执行多次重开、核对车辆与起点，并在故障时退出的实测。

在这些证据补齐之前，不启用持续采样，不关闭 T03，不把回放测试视为实机能力。

## 软件验证（部分实现）

全量 75 项 pytest 通过，其中 31 项覆盖赛事运行；mypy、Ruff 检查与格式检查通过，离线构建 wheel/sdist 成功。合成测试覆盖限次重开、独立尝试标识、错误起点、菜单误判、卡住超时、用户停止、失焦、过期/重复画面、遥测异常和证据损坏恢复。

双轴审查发现并修复了摘要与日志未绑定、原始遥测未纳入完整性检查的问题；最终规范复核无遗留问题。规格审查保留上述实机适配、真实完成信号和多轮自动重开缺口，Issue #4 继续开放。通过测试不意味着本机已经可以自动重开或自主训练。
