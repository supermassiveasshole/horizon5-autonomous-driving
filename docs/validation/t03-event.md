## 尚缺实机证据与实现

- 实际季节，以及时间/天气重开一致性；当前季节选项未固定。
- 第二次独立完赛的识别，以及退出赛事、恢复位置变化等更广泛的反例；现有完成正例仅来自同一次人工完赛。
- 非起点失败位置的恢复、该菜单适配器的实机 F8/断流演练和更长时间重复稳定性。

在这些证据补齐之前，不启用持续采样，不关闭 T03，不把回放测试视为实机能力。

## 软件验证（部分实现）

本轮全量 93 项 pytest 通过，其中 39 项赛事核心测试、9 项真实 UDP/时钟的菜单适配器测试；mypy、Ruff 检查与格式检查通过。覆盖限次重开、独立尝试标识、错误起点、菜单误判、卡住超时、用户停止、按键中失焦、截图失败/过期、遥测异常和证据损坏恢复。新增回归验证零输入期间 120 ms 的 F8/失焦仍被锁存，以及截图或关闭阻塞时主流程有界退出。真实截图、游戏响应和菜单成功以本节实机证据为准。

`uv build --offline` 成功生成源码包与 wheel；检查确认包含新菜单适配器，且未包含 `.tools/`、`.scratch/`、`runs/` 或 `.git/`。

前一轮双轴审查修复了摘要与日志未绑定、原始遥测未纳入完整性检查的问题。本轮审查又发现零输入等待期短暂 F8/失焦可能漏检，以及同步截图可能阻塞主循环，均先建立失败回归再修复；probe-05 验证修复后仍能实机重开。Issue #4 仍开放；短时菜单循环通过不等于自主训练可用。
