## 方法与数据

方法为 `segformer-cityscapes-b0-v1`，固定 NVIDIA 权重及预处理配置；来源、许可、复现步骤和评估协议见 [像素道路估计](../perception.md)，版本清单见 `configs/perception-t23.json`。协议及阈值在首轮预测前写入；独立审查后进一步明确未知候选不进入高分决策分母，在这之前没有收到或查看人工留出标签。模型、置信阈值和像素映射没有依照留出标签调整。

使用 [数据集示例](../../configs/perception-dataset.example.json) 的五段连续记录，共 300 帧、960×540：

|---|---|---|---|

## 实机离线运行

最终代码复跑产物在本地 `runs/t23-pixels-v3`，没有运行控制器或发送驾驶命令。RTX 4090；PyTorch `2.8.0+cu128`、Transformers `4.57.6`、float32、单帧。依赖锁在 `uv.lock`。启动后使用全部 300 帧统计，未剔除冷启动首帧。

| 指标 | 最终复跑 |
|---|---:|
| 有效输出 / 无效输出 | 300 / 0 |
| 神经网络推理中位数 / p95 / 最大 | 24.783 / 28.294 / 258.672 ms |
| 完整逐帧处理中位数 / p95 / 最大 | 64.581 / 70.012 / 310.654 ms |
| CUDA 峰值 allocated | 181,634,048 字节（约 173.2 MiB） |
| 保守 150 ms 结果预算超限 | 134 / 300；开发 100/120、留出 34/180 |
| 同片段连续图像对 | 开发 118、留出 177 |

推理时间包括 CPU 预处理、GPU 推理及 CPU 输出；完整处理还包括候选映射、像素边界、哈希及图像文件保存。CUDA allocated 不是游戏与驱动的总显存占用。预算超限将原始观测交付年龄与完整离线处理时间相加，包含磁盘保存，不等于实测在线控制延迟；全部输出仍为 `online_usable=false`。原始 T22 的 100 ms 输入观测条件不变。

开发集原始边界位移中位数 11 px、p95 248 px；留出为 9 px、203 px。这是相邻图像行端点的移动，混有相机/道路运动和最长路面段的切换，**不能称为纯感知抖动**。原始无标签报告保留不变；导入人工标签的新报告见下节，仍为 `geometry_ready=false`。

开发原图/叠加抽查显示路面局部漏分、引导线和 HUD 附近疑似误分；车身作为障碍候选也可能进入输出。这些是定性观察，不能替代人工标签。未知、低分和错误候选均保留，未通过挑帧或调低阈值掩盖。

`t23-pixels-v1` 是中间诊断，CLI 曾因沿用遥测结束判断报错，且预算只统计推理时间；均已修复。`v2` 与 `v3` 的 300 个分类/分数 PNG 哈希逐个一致。v2 原图核验页与 v3 的数据集/协议哈希相同，已开始的人工标注兼容，不需重画。给用户的 `runs/t23-annotation-guide/index.html` 使用开发录制第 400 帧（不在选片内），叠加形状仅为讲解草图，不导出为真值。
