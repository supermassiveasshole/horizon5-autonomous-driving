# T10 / #11：异步数值运行器中的冻结 SAC 探索

2026-10-02。新增 `SACSamplingActor`，把实际冻结 CPU SAC 的有界随机探索接到既有
`RealtimeRun`，保留确定性评估接口。没有启动 FH5、Steam、DXGI、游戏 UDP 或手柄；
外部观测和接收命令由合成适配器提供，结果不代表游戏物理或驾驶改善。

## 本次范围

- 策略直接读数值 RGB、实际时间特征及成功发送的动作历史；权重在一次运行中冻结。
- 噪声按版本化算法、种子及记录中的决策身份确定，不依赖预热或跳帧后 RNG 已前进多少次。
- 动作继续受已有幅度、变化率、租期、推理截止及独立监督限制；既有实时日志保留实际发送和停止结果。
- 冻结后独立重放需要相同模型、噪声规则和种子；即使改写种子声明并重新计算报告摘要，也不能重现原预测。
- 清单记录实际 CPU 推理设备。没有将合成模型标为已获原生驾驶资格。

## 验证

通过已约定的 `run_experiment` 边界，训练小型实际 BC / SAC fixture，随后执行异步短段和离线重放。

设备记录的第二次 RED 显示 `inference_device=None`；补充实际 CPU 声明后专项回归
`tests/test_sac_realtime_sampling.py tests/test_sac_evaluation.py`：**13 passed / 57.22 秒**。

本地证据为 `runs/t10-realtime-evaluation-regression-20261002-results.xml` 及同名前缀的测试目录。
覆盖有界动作、权重不变、无 worker 预热的独立精确重放、种子与预测一致性，以及原有确定性 SAC
批次、上下文变化、发送失败和独立执行核验。合成执行不获自动晋升资格。

整库回归需在先前已运行的主分支作业及 #10 队列之后执行；之前版本的整库结果不覆盖本增量。
