# Triage Labels

The default vocabulary is confirmed. Use these exact strings in GitHub Issues.

| Canonical role | Repository label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Waiting for information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for autonomous agent implementation. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be actioned. |

When a skill names a canonical role, apply its repository label. Reuse an existing exact match; create a missing label. Preserve unrelated labels. Edit this mapping if the repository vocabulary changes.
