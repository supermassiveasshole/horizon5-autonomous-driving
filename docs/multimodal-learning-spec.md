# 视觉必选的多模态 BC→SAC 规格增量

版本：1.1（2026-09-29）。原 v1.0 的 3 项新增、9 项修订已发布；本轮视觉导航增量与任务拆分已获批准并发布。本文补充 [PRD v1.2](PRD.md) 与[驾驶学习主方案](driving-learning-design.md)，约束后续实现；不表示已有驾驶模型、训练或实机验收结果。范围来源见[决定记录](scope-decisions.md)，取舍见 [ADR 0004](adr/0004-multimodal-learning-before-geometry.md)。

## 已确认需求与本批实施方案

**已确认：** 实际驾驶策略必须输入视觉，融合本车状态、因果动作历史和可选预录航点进行监督/模仿初始化，再通过真实交互 RL 自主改进。道路分割与精确左右边界不再是所有学习工作的总前置。固定车/调校、官方歌利亚、空场优先、无接管/无倒带正式成绩、反蹭墙及未知结果隔离保持不变。

**已批准的工程方案：** 保留双轴 BC→SAC，先做同步短段、多模态离线 BC、有界短段实跑、自动重复评估，再进入 SAC。传统基线及米制几何作为并行方向；Dreamer、纯视觉驾驶和外部项目移植不纳入本批。网络大小、图像尺寸、历史长度、预训练/微调阶段及损失权重由实施实验确定并版本化，不重问已确认的范围。

## 观测、监督与动作契约

- 实际 actor 输入为包含道路/导航指引的截图短期历史、本车状态、因果动作历史与可选的车体坐标局部参考航点。参考是否必选按版本显式声明，无参考须在训练/评估中覆盖；旧 #26 契约保留必选，不以本次文档更新冒称实现。图像须真实参与计算；记录画面、算奖励或把无用图像参数传入模型均不满足视觉接入。
- 逐次决策记录图像捕获、可用及交付时刻、遥测接收时刻、片段号、路线版本和观测年龄。只使用决策时刻已可用的数据；不输入事后配对的未来遥测。图像陈旧、损坏或缺失必须可见，不重新打时间戳。
- 固定追尾远是相机档位，非固定外参。保存缩放、归一化、历史构造、缺失掩码及版本。主线不要求先把像素换算为米制道路。
- 若提供历史参考，则在运行前冻结，可由独立历史全程遥测提供。历史参考是允许使用的路线先验，不是本次运行的未来观测、唯一合法线路、道路边界或最优赛车线。实时视觉导航可以隐式学习，不以专用提线模块作为前置。歧义定位不能强选较远里程获取奖励。
- 人类示范必须标定输入设备、动作语义和观测对齐。原始手柄读数、策略请求、限幅后动作、驱动成功下发与游戏响应分开记录；现有人类遥测 Steer 不可直接作为摇杆真值。双踏板、手刹等动作不能无声压成有符号纵向命令。
- BC 主要监督可信双轴动作；未来局部航点是可选辅助目标，可用同一前向片段的未来位置自动生成。目标坐标以样本当时姿态变换，越过片段尾部/恢复边界的目标屏蔽，未来信息不得回流 actor 输入。
- 按独立录制回合划分训练、开发和最终留出，跨路线结论还须按未训练路段留出；不能随机拆邻帧或用留出统计拟合预处理。数据少时先报告初始化结果，不夸大泛化。T23 留出已经用于诊断，新方法不得继续把它称为未见过的最终评估。

## 离线训练、实机与有效性分开

离线观测构造和 BC 初始化不依赖自动重开、传统控制器完赛、可信全程走廊或精确分割。这些切片只在记录与模型上运行，不发送游戏输入。

首轮实机 BC 仍需要真实输入/停止验证、核验过的有限练习范围、可解释的尝试结果及人工置于可用起点。沿用已实现的局部路线工具，允许只核验小范围保守区域；不要求沿全程测两侧或精确还原整幅道路。保守区域外表示超出已核实实验范围，不能自动等同于游戏违规。缺口保持未知，不通过缩窄数据描述伪造 T04 已验收。

从短时校准扩展为闭环策略控制需要单独验证时序、租期、推理超时、停止和持续记录；现有 T02 的短时通过不等于无人值守许可。首轮试跑可人工准备；自动重复评估和 SAC 采样必须使用已验证的有界重开流程，保留失败退出。不假设任意位置重置、加速模拟或多实例。

奖励与正式有效性保持独立：确认进度依据已核验局部任务与检查点连续性，未知区域不获得虚假的合法进度；视觉特征、轨迹贴合或模型高分不能证明合法。若后续希望引入较弱的训练进度代理，应另写奖励版本和有效性隔离实验，不能由本次“取消分割前置”默许放宽规则。

缺图/过期时执行预先验证的停止或显式回退，保留控制归属；不把降级成路线+遥测驾驶的区间算作完整多模态策略完成。正式成绩继续排除接管、倒带、违规或未经核验的结果。

## 可训练表征与 RL

BC 初始化 actor 不表示 critic 已初始化。SAC 必须明确 critic/目标网络准备、示范与在线样本混合、探索启动、模仿约束减弱/退出及冻结候选评估；学习实际改变两轴动作，不设永久小残差上限。

视觉编码器可以阶段性冻结、解冻或微调，但继续学习应被接口支持。经验保留原始图像/因果历史引用及预处理版本，使表征变化后能重算；仅存旧 latent 的模式必须绑定冻结编码器，不能跨版本混用。续训保存视觉编码器、优化器、目标网络、温度、归一化/历史配置与原始经验依赖。

首轮有界 SAC 已须测量游戏、采样、训练共享资源时的响应和容量，允许分阶段训练，不把 GPU 容量当作实时性保证；持续运行预算票继续检验更长时间条件。

## 三项视觉证据分别验收

1. **接入：** 实际驾驶 actor 的前向计算确实融合真实截图；日志可定位逐次输入和动作。
2. **利用：** 固定路线与遥测，对冻结策略做离线遮蔽/错配等干预并报告动作响应，区分正确使用导航条件与错误的地标/HUD 关联；依赖可见循迹线本身不是作弊。响应存在不自动证明理解正确，导航专项另测同路口不同去向与进入状态。
3. **收益：** 使用独立训练或合格既有的路线+遥测诊断对照，在同条件真实重复驾驶中比较；突然给多模态网络喂黑图的退化不等于视觉收益。视觉增益可能不显著，负面结果保留。

第 2–3 项的完整对照不阻塞首轮 BC/SAC 训练；不能因此将尚未验证的收益写成已实现。无视觉模型只用于诊断对照，不替代用户要求的主线策略。每次策略/编码器升级后，视觉结论须按版本复验。

## 测试与实施顺序

仍通过实验运行入口验收：输入固定配置及真实/回放环境，检查逐次因果观测、实际动作记录、完整尝试及版本选择。分别提供独立预期的软件/故障回放、必要实机检查和冻结策略重复驾驶证据；训练 loss、回放通过与真实驾驶能力不能互代。

| 顺序 | 可见交付 | 必要条件 |
|---|---|---|
| 因果观测 → 同步示范 → 离线 BC | 可追溯输入/动作样本与留出预测 | 已验证的遥测、RGB 采集和动作来源；不等精确几何、传统控制或重开 |
| 有界短段实跑 | 多模态策略真实驾驶、全部尝试与失败 | 局部独立核验与闭环控制/停止；允许人工准备起点 |
| 重复评估 → 首轮 SAC | 实际采样、更新及冻结驾驶对照 | 有界自动重开、独立有效性与奖励；视觉收益对照可并行 |
| 续训与全程推进 | 可恢复学习、全程覆盖及实际成绩 | 原有自主循环、全程有效性和个人比较要求继续适用 |

传统控制基线和米制道路是并行方向。T22 采集与 T23 负面感知评估作为已完成实验保留；不据此声称已有可信视觉动作示范或道路几何。
