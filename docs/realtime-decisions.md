# 容错数值决策（T34 / #36）

状态：首个软件切片。已有共享期限状态机、真实常驻推理线程、独立动作监督、有界旁路与故障时间线；**尚未接入 FH5 只读影子适配器或真实执行器**。#36 保持开放，后续组合 DXGI、UDP、独立任务范围核验及冻结 Δt 模型，完成 10/20 Hz 实机影子对照。#9 负责游戏中的实际发送和车辆响应。

## 实验接口

`run_experiment(RealtimeReplay(...))` 输入带绝对时间的安全状态、数值历史和模拟推理服务返回时间，生成确定性期限/动作回放。推理挂起用 `InferenceReply(delay_ms=None)` 表示；它不加载模型、不采集屏幕、不连接手柄。

`run_experiment(RealtimeRun(...), realtime_environment=..., numeric_actor_factory=...)` 启动真实线程。环境边界提供 `read`、独立 `signals`、模拟 `send` 和 `close`；生产游戏控制适配器不属于本切片。`source_kind` 只接受 `synthetic` 或 `shadow`。影子环境的 `send` 必须为空操作，候选动作不充当实际动作历史，缺少已验证真实输入时保持 action mask 为 false。

模型加载和一次预热在常驻推理线程完成，随后才启动决策调度。最多一个任务在途；忙时跳 tick。原生推理不能强行取消，挂起时停止会话并报告未释放线程，不再建线程替代。

## 期限与恢复

默认决策 20 Hz，也可配置 10 Hz；推理截止 80 ms、动作绝对有效期为决策时刻加 150 ms，独立监督器约每 5 ms 检查。最新图像/遥测上限分别 100 ms；历史按源时间计算 age 与相邻 Δt。发送前再核对旧输入年龄、最新安全状态和采集 epoch。重复旧源帧不续租，迟到、跨 epoch 或租期已过的结果不发送。

短时缺图、单次推理超时和旁路降级可跳过后恢复。**150 ms 动作到期发送全零，但保持尚有效的会话；250 ms 无有效决策或推理挂起则硬停止锁止。** 新图不能解除硬停止；重新运行实验是明确的新会话。F8、失焦、非活动、游戏时钟倒退/停滞、车型变化、超速和环境提供的独立任务范围故障仍可提前锁止。未就绪期间不发送输入。

发送记录含 owner、请求/返回时间、decision ID、绝对有效期和前次动作持续区间。`previous_hold_ns` 按两次成功发送返回计算，另列调用时间界定的上下界，并明确标记为返回时刻代理；游戏实际应用时刻未核验，部分发送失败时不填确定的 hold。模型只使用当时已返回的历史动作，未来才确定的 hold 不进入输入。Windows/Python 不是硬实时系统；目前 send/close 的真实驱动卡死行为未验收，不能把模拟执行器结果当作设备保障。

## 存档与资格

关键命令/决策与 UDP 原包使用有界优先级队列，编码、hex、写盘与哈希在旁路完成。RGB 数值图另有 8 项/32 MiB 待写上限和默认 512 MiB 总预算，报告预览在旁路生成。满队列、预算耗尽或写入失败不堵决策。

序号缺口、未写完图像、发送失败和未结束推理会使记录不完整；相关记录不能直接用于训练、精确回放或晋升。完整记录只表示具备进一步核验的条件，当前没有实时记录的独立精确重放验收。所有合成/影子记录的训练与晋升资格均为 false。

`report.html` 同一决策下显示选帧、age、Δt、推理截止、动作有效期、归零及旁路状态；`report.json` 保留完整数据。源帧到可发送结果的统计不等于实际游戏动作延迟。
