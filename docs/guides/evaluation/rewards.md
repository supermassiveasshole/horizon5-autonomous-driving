# 局部奖励与终止结算（T07 / #8）

`run_experiment(RewardReplay(...))` 离线读取完整录制、冻结局部任务和独立证据，输出每个前向片段的奖励标签。它复用尝试判定，不发送控制，不训练策略，也不将评测路线加入 actor。任务与证据格式见[局部尝试](attempts.md)。

```powershell
uv run --locked fh5 reward-replay runs/my-recording --task runs/my-task.json --reward configs/reward-local-v1.json --evidence runs/my-review.json --output runs/my-rewards
uv run --locked fh5 reward-audit --reward configs/reward-local-v1.json --output runs/reward-counterexamples
```

输出目录应不存在。`report.html` 展示逐段结果，详情包含每步进度、时间、终止项、折扣和任务状态；`rewards.json` 保存结构化结算，`validity/` 保留独立判定与冻结证据。奖励文件原文和 SHA256 一并保存。`reward-audit` 创建明确标记为 synthetic 的原始包、几何、事件证据和完整回放，比较完成、早撞、放弃、停车、往返及导航反例；不是实机驾驶。

退出码：0 表示全部奖励标签可用，或合成反例通过；4 表示存在隔离/无法开始的片段，或反例失败；2 表示配置/文件错误。**一次真实驾驶失败可以有可用的负奖励标签，因此退出码 0 不代表驾驶成功。**

## 奖励口径

规则版本 `local-physical-reward-v1`。当前候选参数：合法进度总预算 P=1、整个任务时间预算 C=1、成功 B=2、失败 F=3；任务时长 T 内折扣衰减一半。均是可更改、需重新核验的候选，不代表已找到最优奖励。

每段从首次核实的局部起点开始，初始位置不领奖。进度只取同段最远已确认合法里程的增量，除以剩余路线长度；重复经过、未核实道路、漏点、位置跳跃、速度越限不增加进度。时间取遥测游戏时钟的正向差值，不用接收延迟或模型调用次数。

对于时长 dt，令 λ=ln(2)×半衰期数/T，d=exp(-λdt)。一步奖励为：

`r = -(C/T) × (1-d)/λ + d × (进度项 + 终止项)`。

λ=0 时，时间项为 `-(C/T)×dt`。完整回报为各步 r 乘此前累计折扣再相加。报告同时显示未折扣原始分量、区间折扣和最终 r；事件计在区间末端，时间成本连续积分，避免只因包频率不同改变时间扣分。

同时间戳遥测暂不产生位移奖励，待时钟前进后共同结算，记录合并包号；末尾有位移但尚无正时长时隔离。坏包、无法解释的时钟/位置跳变及超过配置连续性上限的区间不能用于正常结算。这不是要求图像零丢帧；图像调度和实际动作保持区间由后续采样接口负责。

最远进度、任务起点、下一检查点、剩余物理时长和无进度剩余时间属于独立任务状态。它们不能被当作已加入无参考 actor 的字段。当前输出奖励标签与遥测引用，**尚未导出包含因果图像、实际动作保持和 bootstrap 输入的 SAC transition**。

## 终止、截断及不确定性

- 完成、确认驾驶失败/蹭墙/复位/草地捷径、超速、漏点、任务超时或停滞期限属于真实终止。失败优先于同包的到达；确认提前停止按放弃结算。进入任务时已失败可产生独立初始负奖励，不伪造此前动作。
- 暂停、倒带、重开、接口恢复及录制提前结束属于外部截断；若此前有确认驾驶失败，仍先保留失败结算。动画排除，恢复后的片段重新开始，回报不跨段相加。
- 确认失败落在排除区入口或重复 tick 上时，独立 `terminal_adjustment` 保留负反馈，并在最后已知物理时刻折扣；不伪造额外时间、动画状态或动作转移。重复 tick 的失败因转移时序不足仍隔离，终止且禁止 bootstrap。
- 截断的估值引用只指向本片段最后真实状态，绝不指向重置后的包；用于学习前还须取得该时刻的真实因果 actor 观测。隔离片段没有 bootstrap 资格。
- 缺独立覆盖、疑似违规、来源复用、条件/控制归属不符及接口记录损坏会隔离标签。确认的负面事件仍留在报告中，不把不确定性当成确定碰撞或合法驾驶。
- 导航重算和线消失只记录；距离变短和停车都不是到达依据。确认改目的地截断原任务，隔离在整份录制中持续有效，重开不能自动恢复旧任务资格；须另冻结任务协议并开始新录制。自由驾驶长期评分未开放。

局部有效性规则 v2 增加导航事件、任务阶段边界及显式接口故障清单，旧 v1 结果保留。奖励不覆盖正式全程结论，也不能用于直接晋升版本。

## 定标与适用范围

配置要求有限数值和显式版本，并检查保守的完整回报界：最晚合法完成的下界须大于任意已确认失败的上界。失败上界允许最多一个已声明物理采样间隔的超时检测延迟；进度最多 P。每个实际任务按自己的 T 重新检查，不能仅任意提高罚分。`reward-audit` 再通过同一实验入口执行完整反例并报告排序。

这个检查依赖合法进度、时间和终止证据正确，不证明全局无奖励投机。已有实机证据是历史短段重算，尚无自动违规识别准确率或 RL 驾驶改善结论，见[T07 验证记录](../../validation/t07-rewards.md)。
