# 有界局部路线跟随（T05 / #6）

`run_experiment(TrackingDrive(config_file, output_dir), environment=...)` 通过已有 `ControlEnvironment` 接收遥测、下发动作并保存完整记录。它是传统反馈基线；不加载 BC，不训练 RL，也不使用截图。软件闭环已用独立的合成车辆检查；原车原调校的真实连续弯道仍待验收。

## 配置与入口

复制 `configs/tracking.example.json`，填写已核实局部路线的路径与 `route.json` SHA-256。示例的零哈希和路径是占位值，不能直接驾驶。路线包必须通过既有走廊和检查点核验，长度为 3–60 米；这不代表驾驶、碰撞或全车扫掠验证已完成。原车、调校、辅助、蓝图保持原实验条件。

```powershell
uv run --locked fh5 track --config runs/tracking-config.json --output runs/tracking-001
```

默认仅校验，不连接手柄、不创建记录目录。真实使用另加 `--live`，使用可选 `control` 依赖及已安装的虚拟手柄驱动；准备与停止操作见[控制说明](control.md)。本轮未执行该实机入口。输出目录必须不存在。

前台、活动遥测和起点条件满足后才开始：车速不超过 0.5 km/h、起点投影里程不超过 1 米、离参考线不超过 0.5 米、朝向误差不超过 0.3 rad。初始失焦/菜单等待有时限，开始后失焦或非活动即停止，不自动再次接管。

## 跟踪、减速与纠偏

- 纯跟踪转向使用车体坐标下的前方参考点；前视距离为 2–5 米。前方三点曲率限制目标速度，并按配置制动减速度提前减速；局部终点前保留停车余量。
- 速度目标不超过 12 km/h，必须比硬停止线低至少 3 km/h；硬停止线不超过 15 km/h。转向至多 ±0.5、油门至多 0.25、刹车至多 0.5；同一命令不同时给油和刹车。之前 0.35 油门的零转向采集例外不适用于本控制器。
- 距参考线超过 0.75 米或朝向误差超过 0.5 rad 时进入纠偏，目标最多 6 km/h；回到 0.4 米内且朝向误差小于 0.25 rad 才退出。所有纠偏累计共享一个时间预算，反复进入不能重置预算。
- 偏离超过 1.5 米、朝向误差超过 0.9 rad、未知/未覆盖区域、漏点或不连续位置立即停止。无新增至少 0.25 米进度达到超时也停止。这里的区域外表示未被核实，不自动判定游戏违规。
- 最长跟踪 30 秒，再制动至多 3 秒。接近静止（≤0.5 km/h）释放 LT，避免继续按 LT 倒车。到达局部目标并刹停，且连续合法进度已确认到该目标，才记 `local_end`；投影到达但检查点仍待通过记 `unconfirmed_target`。时间用尽仍保留 `time_limit`，未停下则为 `not_stopped`。异常解除输入不保证车身静止。

几何、轴距、转向比例、制动与侧向加速度参数都是待实测的候选，未标定为第六元素物理模型。当前示例沿用 0.25 油门上限可能不能在真实车辆上维持目标速度；若如此保留 `no_progress`，不能自行套用直行采集的增幅。

## 实时保护与回放证据

20 Hz 为默认调度目标；独立驱动看门狗保持 F8、失焦和 250 ms 租期。运行时检查每一个收到的包，最新正常包不能覆盖中间坏包、暂停、车型变化或时间异常。过期遥测不驱动新决策；调度或发送阻塞达到 250 ms 停止。错误、归零失败与关闭失败独立保留。这些软件机制不是操作系统级硬实时保证。

输出 `packets.jsonl`、`commands.jsonl`、`control.json` 和自包含报告；`tracking-route/` 冻结路线、核验资产及其证据，并在回放验证哈希。原路线移动或修改不影响已保存回放。报告显示轨迹、定位状态、速度、实际命令及最后观测位置。

每条驾驶命令记录控制归属 `baseline`、模式 `tracking/recovering/braking`、目标速度、原始观测包号/接收时间、发送调用起止时间和返回值；最终解除归属 `stop_guard`。`control_source=policy` 在会话层表示自主控制，`controller_kind=route-feedback-v1` 明确它是传统控制器。失败与中断不裁剪为成功示范。驱动返回成功不等于游戏采用动作；人类接管、碰撞和真实延迟需要独立证据，本接口未实现自动检测所有这些事件。

```powershell
uv run --locked fh5 replay runs/tracking-001 --report runs/tracking-001/review.html
```

回放无驱动依赖。`track` 仅在记录正常结束、局部目标刹停且归零成功时返回 0，其余驾驶结局返回 4，参数错误为 2。回放、模拟和单次控制都不开放持续采样。本切片保留可审计的动作记录；尚不能冒充带同步视觉的新 BC 数据集或自主学习收益。实测缺口见 [T05 验证记录](../../validation/t05-tracking.md)。
