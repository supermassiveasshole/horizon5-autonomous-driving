# T23 像素道路估计

## 冻结方法与评估协议 v1

2026-09-29；在运行候选、查看留出预测前固定以下口径。测试沿用已确认的 `run_experiment` 入口；构造用例验证记录、错误处理与计分，不能证明真实识别准确性。

候选为 [NVIDIA SegFormer-B0 Cityscapes 权重](https://huggingface.co/nvidia/segformer-b0-finetuned-cityscapes-1024-1024)，固定修订及文件哈希在 `configs/perception-t23.json`。模型卡链接的 [NVIDIA 许可](https://github.com/NVlabs/SegFormer/blob/master/LICENSE) 限定非商业研究/评估；权重留在本地忽略目录，不随仓库重新分发。Transformers 使用 Apache-2.0，PyTorch 使用 BSD-style，NumPy 使用 BSD，Pillow 使用 HPND；实际依赖由 `uv.lock` 锁定。

模型虽按 1024×1024 命名，上游处理器实际配置为 512×512。本候选明确采用 RGB 双线性缩放至 512×512、ImageNet 均值/标准差、float32；输出 logits 双线性上采样至原图大小再 softmax。固定权重、无训练、无测试时增强。记录硬件、软件版本、加载耗时、逐帧预处理至 CPU 输出耗时；CUDA 计时同步，首帧不从耗时统计中剔除。

原类别 road → 路面候选，sidewalk → 路肩/人行道候选（只是城市人行道代理），建筑/墙/围栏/杆/标志及人物/车辆 → 障碍候选。植被、地形、天空和最大 softmax 小于 0.7 的像素 → 未知。未知不等于可驾驶。softmax 是模型分数，未经 FH5 概率校准；不得声称是识别正确率。蓝色引导线不作为真值。未检测到障碍不证明路面无障碍。

左右边界定义为指定图像行上最长连续路面候选段的两端；没有候选时缺失。这是容易复现的像素基线，不推断车身后方被遮挡的路面、不换算米制路宽或生成 verified 走廊。

## 数据划分与人工核验

开发来源 `t22-rgb-20260929-023136`，留出来源 `t22-acceptance-20260929-024718`。两次录制分别处理，片段与原始文件哈希写入数据集清单。每个集合至少六张核验帧，来自连续片段；不随机拆相邻帧。少量相邻帧用于测量边界误差的变化，不用于声称跨路线泛化。

核验页面只显示原图，不载入预测。人逐帧描绘可见路面多边形，车身、HUD、无法辨认的遮挡用忽略多边形排除；蓝色箭头若可确认覆盖路面则属于路面，阴影中的可辨路面同样标为路面。其余可观察像素为非路面。模糊边缘宁可忽略，不凭模型猜测。左右边界只标在能看清的指定横线上，画面外或被车身遮挡的端点留空。标签保存标注者、来源哈希、协议哈希与逐帧备注，禁止自动把模型输出转为人工标签。

覆盖记录区分直道、左弯、右弯、路肩/护栏变化、低/中/高速，以及车身遮挡、引导箭头、HUD、阴影、运动模糊。缺少场景逐项列出。核验集中可故意保留离路和难例；不能只挑好看的预测。留出结果一旦看过，该集合只能作为已知诊断集；修改方法后需要新的留出记录。

## 预先固定的指标与使用门槛

- 路面 IoU、漏检率：在人工可观察区域按像素累计；忽略区不计分，未知预测在真实路面上计漏检。
- 左/右边界 MAE：在人工标明可见的端点上分别报告像素误差；模型缺失单报漏检率，不把缺失丢掉后声称低误差。
- 高分错误率：最大 softmax ≥0.9 且未弃权的路面/非路面候选中，与人工路面真值不符的比例；同时报分母、未知率。未知像素不进入决策分母，不能用大量天空/地形弃权稀释错误。非路面类细分准确性尚未标注，不混成全类别准确率。该口径在独立审查后明确，尚未收到或查看人工留出标签。
- 跨帧变化：只在同录制、同片段、间隔 ≤200 ms、无遥测/视觉断点的相邻帧上测边界移动。原始移动包含相机与道路变化，不称为纯模型抖动；有相邻人工边界时，另外统计预测误差之差的绝对值作为残差抖动。
- 耗时：全部被处理帧的端到端推理时间 median/p95/max，包含 CPU 预处理和结果回传；另报包含候选映射、边界提取和文件保存的完整处理时间。原始观测交付年龄加完整处理时间超过 150 ms 标过期；离线运行始终不视为在线可用控制输出。

门槛见冻结配置：每组至少六张人工帧，留出路面 IoU ≥0.85，左右 MAE 各 ≤15 px，端点漏检 ≤10%，高分错误 ≤2%，推理 p95 ≤80 ms，残差抖动 ≤10 px。所需覆盖不全、标签不足或指标不可计算均为 **未验证**，不能算通过。通过只允许继续几何验证；接入驾驶仍需后续票独立验证。负面结果保留，T23 不以达到精度门槛为完成条件。

## 运行与核验

安装 `uv sync --locked --extra perception --extra events`。已有控制环境另加 `--extra control`，避免同步时移除该可选依赖。CUDA 轮子固定来自 PyTorch cu128 索引，支持 `--device cpu` 回退，但耗时须另报。本机权重目录为忽略的 `.tools/models/segformer-cityscapes-b0`；从上述固定修订下载 `config.json`、`preprocessor_config.json`、`pytorch_model.bin`，并保留上游 `LICENSE`，启动时检查配置里的哈希。禁止 `trust_remote_code`，读取本地权重使用 `weights_only=True`。

```powershell
uv run --locked --extra perception fh5 perceive --dataset configs/perception-dataset.example.json --protocol configs/perception-t23.json --model-dir .tools/models/segformer-cityscapes-b0 --output runs/t23-example --device cuda
uv run --locked --extra perception fh5 perception-replay runs/t23-example --report runs/t23-example/review.html --labels path/to/fh5-t23-labels.json
```

输出目录必须是新目录。示例数据集绑定既有本地录制的哈希；其他电脑需要对应原始录制，或明确创建新数据划分。按录制顺序计帧号（从零开始），不是遥测包号。源图和模型均不上传。输出包含方法与源码哈希、冻结协议、数据集清单、分类/分数 PNG、叠加图、原图核验页 `annotate.html` 和回放 `report.html`；PNG 三通道依次是候选类 0–3、原始 Cityscapes 类 0–18、最大 softmax 的 uint8 分数。模型通用类别不能直接识别精确 FH5 路肩或碰撞。

先在原图核验页填写标注者，逐帧画路面与忽略多边形、标可见的左右端点、修正场景标签，勾选已核验。下载 JSON 后通过上述入口导入；只读取已核验帧，不接受模型生成标签冒充人工。页面不载入预测，保留独立判断。可导出部分进度，缺失项继续显示未验证。

回放重新核对源图、结果和协议哈希，坏图/坏结果显式标无效。`stale` 是根据原始图像交付年龄加本次离线完整处理时间得出的保守预算检查（含文件保存）；它不测量真实在线队列和调度延迟。离线结果始终 `online_usable=false`。原始 T22 的 100 ms 观测门槛未修改；150 ms 是此独立像素实验的结果预算，不授权控制器采用。早期诊断 `t23-pixels-v1` 只加推理时间，不用于最终预算结论。
